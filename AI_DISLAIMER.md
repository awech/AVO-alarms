# AI Usage Disclaimer

This repository utilizes artificial intelligence (AI) tools (including Large Language Models) to assist with software development lifecycle tasks. 

## Scope of AI Assistance
AI tools were used to streamline and optimize the following areas of this codebase:
* **Code Refactoring:** Restructuring existing code for improved readability, efficiency, and adherence to Python best practices.
* **Test Generation:** Writing automated test suites, mock data, and unit tests to ensure codebase stability.
* **Logging Initialization:** Setting up structured logging configurations, debug statements, and error tracking mechanisms.
* **File Locking** Setting up a file locking structure within the codebase (previously done externally)
* **Documentation:** Generating docstrings, code comments, and function-level explanations.

## Human Oversight & Responsibility
While AI tools accelerated the development process, all AI-generated code, tests, and documentation have been manually reviewed, edited, and verified by human maintainers. Alarm algorithms and detection logic are mostly unchanged and almost entirely untouched by AI tools.
