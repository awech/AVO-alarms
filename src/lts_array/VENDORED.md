# Vendored: lts_array

This is a vendored copy of [lts_array](https://github.com/uafgeotools/lts_array)
for least-trimmed-squares infrasound/seismic array processing.

- **Source:** https://github.com/uafgeotools/lts_array
- **Commit:** 8e9d204 (master, 2026-06-17)
- **Version:** 2.0
- **License:** See LICENSE.txt

## Why vendored?

The package is not on PyPI, and its long-term maintenance and backwards
compatibility are uncertain. Vendoring ensures a stable, known-working version
is always available to this project.

## Updating

To update, clone the upstream repo at a specific commit and replace the contents
of `src/lts_array/` (preserving this file and LICENSE.txt).
